# Монетки

Учёт личных финансов в духе CoinKeeper: доходы → счета → расходы, перетаскиванием монет.
PWA на чистом HTML/JS, без сборки. Данные хранятся только в браузере телефона (localStorage).

robokod · бета

## Файлы
- `index.html` — всё приложение
- `manifest.json`, `icon-*.png` — установка на рабочий стол
- `sw.js` — офлайн-кэш. **После каждого изменения поднимай версию `CACHE`** (`monetki-v2` → `v3`), иначе телефон покажет старую версию.

## Данные
- Первый запуск: «Загрузить CSV» — выгрузка CoinKeeper.
- Копия и восстановление: «Ещё → Данные».
- Файлы с данными лежат в папке `бэкапы/` (она в .gitignore) — в репозиторий не класть, он публичный.
